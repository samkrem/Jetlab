Jetlab was the final project for MIT AeroAstro's Thermodynamics and Propulsion class (16.004). The objective of this lab was to create a geometric model for the JetJoe JJ-1400 mini-turbine, a hobbyist jet engine used in RC aircraft, that accurately matched the performance predicted by thermodynamic and direct assessments.

Our assessments were based on quantities measured or recorded during a run of the JJ-1400. The model and assessments we developed predicted key performance metrics, including pressure ratio, inlet mass flow, turbine inlet temperature, and specific fuel consumption, based on the engine's geometry. Out of ten teams, our model achieved the closest accuracy to the thermodynamic and direct assessments.

This repository uses Python and Object-Oriented Programming (OOP), enabling users to modify inputs and test different configurations to explore engine performance and analyze various quantities.

A more detailed description of the lab and our findings is included in this repository.
